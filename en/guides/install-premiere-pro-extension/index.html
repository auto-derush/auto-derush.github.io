How to install an extension (panel) in Premiere Pro on Windows

2 min read

Many Premiere Pro tools are "panels": small windows that plug into the interface. Here's how they install and where to find them.

What an extension panel is

A panel is a module that shows up in Premiere Pro like any other window (Effects, Project…). It's often delivered as a ZXP file, a package signed by its publisher.

Installing Auto-dérush

  1. Close Premiere Pro.
  2. Unzip the file you downloaded after subscribing.
  3. Double-click Installer Auto-derush.cmd.
  4. Open Premiere Pro, then Window > Extensions > Auto-dérush.
  5. Paste the license key from your email and click Activate.

You can then dock the panel wherever you like in your workspace, like any other window.

Common issues

  • The Extensions menu is empty or the panel doesn't show: make sure Premiere Pro was closed during installation, then restart it.
  • Premiere version too old: Auto-dérush requires Premiere Pro 2022 or later.
  • License message: the panel checks your subscription online when it opens. Offline, it keeps working for 3 days.

Switching computers

A license works on one computer at a time. To move to a new PC, click Deactivate this PC at the bottom of the panel on the old machine, then activate the key on the new one.

Uninstalling

With Premiere Pro closed, delete the com.william.autoderush folder in %APPDATA%\Adobe\CEP\extensions.
