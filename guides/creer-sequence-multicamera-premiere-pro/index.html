Multicam Premiere Pro tuto : créer une séquence pas à pas

3 min de lecture

Un montage multicam tient en quatre gestes : préparer les clips, créer la séquence source, couper en direct, nettoyer. Voici la méthode, dans l'ordre.

Avant de commencer

Le multicam ne marche bien que si les caméras ont enregistré la même scène en même temps. Vérifiez trois choses :

  • Chaque caméra a un clip (ou une série de clips) dans le projet.
  • Toutes les caméras ont capté le son, même un son de mauvaise qualité : il sert de repère de synchro.
  • Les caméras ont la même cadence d'images, ou presque. Sinon, la synchro dérive sur la durée.
Rangez les clips d'un même plan dans un chutier dédié, avec un nom par caméra : Cam A, Cam B, Cam C. Vous gagnerez du temps dans la boîte de dialogue.

1. Créer la séquence source multicaméra

  1. Dans le panneau Projet, sélectionnez tous les clips des différentes caméras.
  2. Clic droit, puis Créer une séquence source multicaméra (Create Multi-Camera Source Sequence).
  3. Donnez un nom à la séquence.
  4. Choisissez le point de synchronisation : Audio si vous avez du son sur toutes les caméras, ce qui est le cas le plus courant. Sinon, utilisez le timecode, un marqueur ou le point d'entrée.
  5. Validez avec OK.

Premiere crée une séquence source qui contient chaque caméra sur sa propre piste, alignée sur le son. Ouvrez-la et passez le curseur sur quelques points de la timeline : les lèvres doivent coller au son sur toutes les caméras. Si une caméra est décalée, recommencez avec un autre point de synchronisation. Pour le détail du recalage, voir Synchroniser audio et vidéo dans Premiere Pro, sans clap.

2. Poser la séquence source dans une nouvelle séquence

  1. Créez une séquence vide, ou glissez la séquence source sur l'icône de nouvelle séquence.
  2. Placez-y la séquence source. Si le clip n'est pas reconnu comme multicam, clic droit sur le clip, Multicaméra (Multi-Camera), puis activez-le.
  3. Choisissez dans la même option la caméra de départ.

Vérifiez sur la piste audio que vous gardez le bon micro. Dans les réglages de la séquence source, vous avez choisi quel son suit : une seule caméra, un micro externe ou le mélange. Pour une interview ou un podcast, le micro externe est presque toujours le bon choix.

3. Couper en direct

  1. Dans le moniteur de programme, ouvrez le menu des réglages (la clé à molette) et choisissez Affichage multicaméra (Multi-Camera View). Les caméras s'affichent en grille.
  2. Lancez la lecture, puis cliquez sur la caméra voulue, ou appuyez sur les touches 1 à 9 : la touche correspond à la caméra.
  3. Pour enregistrer vos choix, activez le bouton d'enregistrement multicam avant de lancer la lecture. Chaque changement crée une coupe dans la timeline.

Vous pouvez aussi couper sans enregistrer : placez la tête de lecture, puis appuyez sur le numéro de la caméra, même à l'arrêt.

Faites un premier passage en entier, sans vous arrêter, même avec des erreurs. Corriger ensuite est plus rapide que de chercher le plan parfait à chaque coupe.

4. Corriger et aplatir

  • Pour changer une caméra après coup, placez la tête de lecture sur le clip, puis appuyez sur le numéro de la nouvelle caméra, ou faites un clic droit sur le clip, Multicaméra, puis la caméra voulue.
  • Pour déplacer une coupe, utilisez l'outil Édition par ondulation (B) ou l'outil Roulement (N), comme sur n'importe quel clip.
  • Quand le montage est fini, clic droit sur les clips, Multicaméra, puis Aplatir (Flatten). Vous retrouvez des clips normaux, plus faciles à étalonner et à exporter.

Avant d'aplatir, enregistrez une copie du projet : l'opération ne se défait pas toujours proprement une fois d'autres modifications faites.
