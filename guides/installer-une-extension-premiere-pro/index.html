Installer une extension (panneau) dans Premiere Pro sous Windows

2 min de lecture

Beaucoup d'outils pour Premiere Pro sont des « panneaux » : de petites fenêtres qui s'ajoutent à l'interface. Voici comment ils s'installent et où les trouver.

Ce qu'est un panneau d'extension

Un panneau est un module qui s'affiche dans Premiere Pro comme n'importe quelle fenêtre (Effets, Projet…). Il est souvent livré sous forme de fichier ZXP, un paquet signé par son éditeur.

Installer Auto-dérush

  1. Fermez Premiere Pro.
  2. Décompressez le fichier téléchargé après votre abonnement.
  3. Double-cliquez sur Installer Auto-derush.cmd.
  4. Ouvrez Premiere Pro, puis Fenêtre > Extensions > Auto-dérush.
  5. Collez la clé de licence reçue par e-mail et cliquez sur Activer.

Le panneau peut ensuite être ancré où vous voulez dans votre espace de travail, comme les autres fenêtres.

Les problèmes fréquents

  • Le menu Extensions est vide ou le panneau n'apparaît pas : vérifiez que Premiere Pro était fermé pendant l'installation, puis redémarrez-le.
  • Version de Premiere trop ancienne : Auto-dérush demande Premiere Pro 2022 ou plus récent.
  • Message de licence : le panneau vérifie l'abonnement en ligne à l'ouverture. Sans connexion, il reste utilisable 3 jours.

Changer d'ordinateur

Une licence fonctionne sur un ordinateur à la fois. Pour passer sur un nouveau PC, cliquez sur Désactiver ce PC en bas du panneau sur l'ancien poste, puis activez la clé sur le nouveau.

Désinstaller

Supprimez le dossier com.william.autoderush dans %APPDATA%\Adobe\CEP\extensions, Premiere Pro fermé.
